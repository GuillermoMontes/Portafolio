# Portafolio
Esta aplicación está creada con **Vite**
Para iniciarla, primero se debe instalar todas las dependencias con un "npm install",
ejecutar el comando "npm run dev"
<br>
Este portafolio está creado por una plantilla de estilos ya preparada de forma responsiva donde fue
personalizada al %100. <br>
Los estilos fueron aplicados por la librería **Tailwind css 4.0** <br>
Para las animaciones se utilizó **Framer Motion** <br>
Otras librerias utilizadas:
**react-toastify** <br>
**react-scroll** <br>
**emailsjs** <br>

##### Deploy utilizado: **Vercel** 
link:  [Mi Portafolio](https://mi-portafolio-gm.vercel.app/)
